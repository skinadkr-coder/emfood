## 이미지 최적화 팁

1. **용량 최적화**: 웹 성능을 위해 각 이미지를 1MB 이하로 압축하세요
2. **해상도**: 
   - 히어로 이미지: 1920x1080px
   - 제품/시설 이미지: 800x600px
   - 인증서 이미지: 원본 해상도 유지
3. **포맷**: JPEG (사진), PNG (문서/인증서)
4. **파일명**: 소문자와 하이픈 사용, 특수문자 제거

## 임시 대체

현재 코드에서는 이미지가 없어도 다음과 같이 표시됩니다:
- 제품 사진 → 이모지와 그라데이션 배경
- 시설 사진 → 그라데이션 플레이스홀더
- 인증서 → SVG 아이콘 플레이스홀더

이미지를 추가하면 자동으로 적용됩니다.
